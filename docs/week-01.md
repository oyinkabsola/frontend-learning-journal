# Week 01 Reflection
## Browsers
This week I learned more about how web browsers work and how they are used to access and display web resources. I also learned how browser developer tools can be used to inspect webpages and understand what happens when a page loads.
## HTTP
I learned that HTTP is the protocol used for communication between clients and servers on the web. I became more familiar with HTTP requests and responses, including methods such as GET and POST, headers, request bodies, and status codes.
## Terminal Tools
I improved my understanding of terminal tools and learned how commands can be used to navigate directories, create files and folders, and interact with development projects. Using the terminal also helped me become more comfortable working with Git.
## Git (Version Control)
I learned that Git is a version control system used to track changes to a project. I learned how commits record changes and how branches allow features to be developed separately before being merged into the main branch.
## Overall Reflection
This week gave me a better understanding of the basic tools and concepts that support frontend development. I now have a clearer understanding of how browsers communicate with servers and how Git can be used to manage development work.
